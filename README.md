## Описание проекта

Веб-приложение в формате Q&A-платформы, где пользователи могут создавать вопросы, просматривать популярные вопросы, отвечать на них и взаимодействовать с тегами.



## Как запустить проект

### Вариант 1. Локальный запуск (через venv)

1. Убедитесь, что установлен Python версии 3.10 или выше.
2. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируйте его:

   **Windows:**
   ```bash
   venv\Scripts\activate
   ```

   **Mac / Linux:**
   ```bash
   source venv/bin/activate
   ```

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Примените миграции:

   ```bash
   python manage.py migrate
   ```

6. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

7. Откройте приложение в браузере:

   http://127.0.0.1:8000/

### Вариант 2. Запуск через Docker Compose

1. Убедитесь, что установлен и запущен Docker Desktop.
2. Перейдите в корневую папку проекта, где находится `docker-compose.yml`.
3. Выполните команду:

   ```bash
   docker compose up --build
   ```

4. Откройте приложение:

   http://127.0.0.1:8000/



## Реализованные страницы и маршруты

| Маршрут | Описание |
|---|---|
| `/` | Главная страница со списком новых вопросов |
| `/hot/` | Список популярных вопросов |
| `/tag/<tag_name>/` | Список вопросов по выбранному тегу |
| `/question/<question_id>/` | Страница вопроса с ответами |
| `/ask/` | Форма создания вопроса |
| `/login/` | Страница входа |
| `/signup/` | Страница регистрации |
| `/profile/` | Настройки профиля |

## Структура проекта

- `manage.py` — утилита управления Django-проектом.
- `requirements.txt` — список зависимостей Python.
- `Dockerfile` — конфигурация Docker-образа.
- `docker-compose.yml` — конфигурация запуска контейнеров.
- `public/` — статические файлы проекта (если используются).
- `templates/` — HTML-шаблоны Django.
- `static/` — CSS, JavaScript и изображения.
- `*/` — Django-приложения проекта.
