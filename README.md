# 2026-VK-EDU-Web-12-Shosheva-Y

Учебный проект по курсу VK Education Web.

## Как открыть вёрстку
Откройте файл `public/index.html` в браузере. 

Вся статика (Bootstrap, иконки, аватарки) хранится локально в папке `public/static/`, CDN не используется.

## Страницы
- `index.html` — список вопросов
- `question.html` — страница одного вопроса
- `ask.html` — форма создания вопроса
- `login.html` — форма входа
- `signup.html` — форма регистрации
- `profile.html` — настройки профиля
- `base.html` — общий layout
- `tag.html` — список вопросов по тегу

## Структура
- HTML — в `public/`
- CSS — в `public/static/css/`
- JS — в `public/static/js/`
- Изображения — в `public/static/img/`
